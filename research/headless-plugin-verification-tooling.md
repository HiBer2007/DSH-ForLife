## 8. Recipe — how I would test my plugin headlessly (verified APIs only)

**(A) Out-of-process, zero code.** `dsh --profile headless --patch .\test.patch.yml "prompt"`, where `test.patch.yml` is an insert list mounting your plugin plus every row it `inject`s; assert on the exit code, the stdout final answer, or the `--json` stream (`session` → … → `final`). Before that, assert composition with `dsh --profile headless --dump-config`, or in-process with `composeEntries(layers)` / `renderConfigDump(...)`. For isolation, `initProfile(dir, ["@deepseek-ai/dsh-base"])` + `loadProfileDirectory(binName, dir, installAnchor, { userLayer: false })`.

**(B) In-process, one prompt to completion** — mirrors `R/dsh-headless/lib/index.js:293-349` step for step:
