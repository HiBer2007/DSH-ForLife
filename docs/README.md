## ⚠️ 约定

1. **新写的临时笔记不要放根目录**（`.gitignore` 已挡掉常见命名）。放 `docs/` 下对应目录，并在本文件加一行。
2. **写作口吻：无人称陈述**。写"根因是…""判据是…"，不写"我发现…""这次唤醒时…"；
   不写会话时间线、不写"第 N 轮"、不写当时的情绪。
3. **原始报错要留**（它是可复现的判据），**过程叙事不留**。
4. **按"会不会过期"选目录**：不变量 / 契约 / 判据 → `docs/notes/`（去掉日期，改文件名时同步改本索引）；
   一次性事故 → `docs/incidents/`（保留日期 + 历史横幅）。
5. **不再设状态快照目录**（原 `docs/status/` 已取消）：状态会过期，属于提交信息与 `EXECUTION_PLAN.md`，
   不进文档库。文档里也别写"当前环境在跑什么"。
6. **文档不记密钥**，只记引用名（如 `apiKeyEnv`）。
